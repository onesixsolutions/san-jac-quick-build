# Use Case: Admissions & Enrollment Advising Chatbot

## Problem
Advisors spend significant time answering repetitive questions about admission requirements,
deadlines, and enrollment procedures already documented in policy docs.

## Solution
Cortex Search over admissions handbooks and policy documents, surfaced via a Streamlit chatbot.

## Data Sources
- Admissions policy PDF
- Course catalog
- Financial aid handbook
- Student handbook

## Expected Outcome
- Advisors get instant, cited answers
- Students can self-serve via a portal interface
- Reduces advisor call/email volume for FAQ-type questions
