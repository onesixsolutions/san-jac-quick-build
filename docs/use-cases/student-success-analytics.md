# Use Case: Student Success Early-Alert Analytics

## Problem
Early identification of at-risk students relies on manual review of grade and attendance data,
which is slow and inconsistent.

## Solution
Cortex Analyst over structured enrollment and performance data enables advisors to ask
natural language questions like "Which students in MATH 1314 have missed more than 3 classes?"

## Data Sources
- SIS enrollment tables
- LMS attendance/grade exports (loaded into Snowflake)

## Expected Outcome
- Faster identification of at-risk students
- Advisors without SQL skills can query data directly
- Consistent, auditable data access
